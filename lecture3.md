lecture 3:

stacks are an adt that defines last in first out
operations include:
push(), adds x to the top
pop(), removes and returns top element
peek(), returns top elem without removing
isEmpty(), returns true if empty
size(), returns num of elements


queues are an adt that defines first in first out (spotify)
offer(x), adds x to the rear of the queue
poll(), removes and returns the front element
peek(), returns the front element without removing
isEmpty(), returns true if empty
size(), returns num of elements
